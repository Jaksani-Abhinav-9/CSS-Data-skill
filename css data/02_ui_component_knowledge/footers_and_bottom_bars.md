# Site Footers & Bottom Bars
Source Attribution: Modern Web Layout Standards

## 1. Standard Parts:
- `.site-footer`: Bottom section with top border, dark background, padding.
- `.footer-copy`: Muted 0.875rem text.

## 2. Scoped Pure CSS:
```css
.site-footer {
  width: 100%;
  background-color: #12141a;
  border-top: 1px solid #272a38;
  padding: 2.5rem 1.5rem;
  text-align: center;
  margin-top: auto;
}

.footer-copy {
  color: #64748b;
  font-size: 0.875rem;
}
```
